# Архивные данные и документы

Активное приложение реализовано на Go и запускается из корня репозитория через `compose.p1.yaml`. Старый Python/Flask/AG2 runtime удалён.

В этом каталоге оставлены:

- `data/mock/` — fallback CSV для чистого клона без выданных хакатоном данных.
- `data/methodology_sources/` — сохранённые методологические материалы.
- `docs/` — предыдущие спецификации и планы реализации.

Manifest банковских PDF для действующего OCR exporter находится в `research/sources.json`.
